# Afham Reviews | افهم تقييماتك ☕

Arabic café-review insights application built with **NLP, scikit-learn and Streamlit**.

## Problem and solution

Reading hundreds of customer reviews manually makes it difficult to identify satisfaction trends and recurring complaint topics. Users upload a CSV containing a `Review` column, and the app predicts **sentiment** (`Result`: positive, negative, neutral) and **topic** (`Attribute`: service, prices, food, drinks, seating, etc.). The dashboard summarizes sentiment shares, ranks the top three topics among negative predictions, and exports the results.

**Current limitation:** each review is assigned exactly one topic, even if it mentions multiple issues. Recommendations should be validated against the actual review text.

## Workflow

1. Clean and inspect labeled reviews in Notebook 01.
2. Train two TF-IDF text-classification pipelines in Notebook 02.
3. Split by normalized review text to avoid exact-review leakage into the test set.
4. Compare Logistic Regression, LinearSVC and ComplementNB with cross-validation and hyperparameter tuning.
5. Evaluate imbalance strategies on **training folds only**, including no resampling, RandomOverSampler and class weighting when supported.
6. Select by cross-validation **Macro F1**; report **Micro F1**, accuracy, precision, recall, confusion matrices and per-class results on the held-out test set.
7. Save the best pipelines; use Streamlit to analyze new reviews.

## Run locally

Train and save both pipelines first. Save them under `Models/` using **exactly** `sentiment_pipeline.joblib` and `topic_pipeline.joblib`. Run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Select **Download sample CSV** in the app, upload that CSV and inspect predictions. Your own CSV needs only the `Review` column, encoded as UTF-8. The app never trains on uploaded user data.

## Results and class imbalance

The following are observed **held-out test scores** shared during development; the before/after test comparison requires both runs on the same split and has **not been independently confirmed**.

| Target | Test Macro F1 | Train Macro F1 | Test-set interpretation |
|---|---:|---:|---|
| Sentiment (`Result`) | 0.684 | 0.958 | Generalization gap; neutral is weakest |
| Topic (`Attribute`) | 0.859 | 0.986 | Smaller but noticeable generalization gap |

For sentiment, the shared held-out test classification report showed Accuracy ≈ 0.785, Micro F1 ≈ 0.785, and neutral-class F1 ≈ 0.47. The reported **CV** best Macro F1 of ~0.860 belongs to a model-selection run and is **not interchangeable** with a final held-out test result; verify which target it represents in the current notebook.

Oversampling duplicates existing training examples and does not guarantee better test generalization. Inspect per-class recall and F1, especially for neutral reviews.

## Caveats

- Sample reviews are synthetic examples, not verified model outcomes.
- The sentiment percentage is the fraction of **predicted labels**, not independently measured customer satisfaction.
- Don't use the held-out test set for repeated hyperparameter selection.
- Load `.joblib` model files only from trusted sources and maintain compatible scikit-learn versions.
